# Inventory and Cashier Management System in C++
### Academic Project

## Overview
This project is a console-based Inventory and Cashier Management System developed using C++ as part of a university programming assignment in the Data Science program at Bina Nusantara University.

The application simulates a simple retail store management system that allows warehouse staff to manage product inventory and cashiers to process customer transactions. The project focuses on implementing fundamental programming concepts such as structures, arrays, validation, loops, conditionals, and file-like data management using procedural programming techniques.

---

## Features

### Warehouse Staff Module
- Add new products
- View product list
- Update product stock
- Automatic product code generation
- Input validation for stock and pricing

### Cashier Module
- Create transactions
- Add multiple products into a single transaction
- Automatic transaction code generation
- Real-time stock reduction after purchases
- Display transaction history and purchase details

## System Workflow

### Inventory Management
1. Staff inputs product information:
   - Product name
   - Product price
   - Product stock
2. System automatically generates product codes
3. Products are stored in the inventory list
4. Staff can update stock quantities when needed

### Transaction Processing
1. Cashier inputs cashier name
2. Product codes are selected for purchase
3. Customer purchase quantity is validated against available stock
4. Transaction total is automatically calculated
5. Inventory stock is updated after successful transactions
6. Transaction history is stored and displayed

---

## Validation Features
The system includes several validation mechanisms:
- Numeric-only validation for stock and quantity
- Product name length validation
- Price range validation
- Purchase quantity cannot exceed available stock
- Menu input restrictions
